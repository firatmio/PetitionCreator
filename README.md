# PetitionCreator

Üniversite öğrencileri için sınav itiraz dilekçesi oluşturma aracı. Bu araç, arayüz üzerinden doldurulan formdaki bilgileri alarak PDF formatında dilekçe oluşturur ve otomatik olarak *indirilenler* klasörüne kaydeder.


## Özellikler

- **Arayüz:** Türkçe, karanlık tema
- **Desteklenen Platformlar:** Windows, macOS, Linux
- **İşlev:** Sınav itiraz dilekçesi formatlı PDF çıktısı üretmek.


## Kurulum

[Releases](../../releases) sayfasından işletim sisteminize uygun dosyayı indirin:

- Windows: `DilekceOlusturucu.exe`
- macOS: `DilekceOlusturucu_macOS.zip`
- Linux: `DilekceOlusturucu_Linux.zip`


## Kullanım

1. Uygulamayı açınız.
2. Formu doldurunuz (Üniversite, fakülte, öğrenci bilgileri, ders bilgileri vb.).
3. "Dilekçe Oluştur" butonuna tıklayınız.
4. PDF dosyası *indirilenler* klasörüne kaydedilecektir.
